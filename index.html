使用说明与连接帮助

使用机器的 DATA 接口连接电脑，在 Chrome 或 Edge 中打开本页，点击“连接 SXC-1”，允许 MIDI / SysEx 访问。连接期间请退出官方 App 或其他读取 SXC-1 的程序。

每页对应一个 Bank，连接时打开机器当前 Bank，网页翻页时机器同步切换。将一个 WAV 拖到空 Pad 会直接检查、转换并上传；已有采样的 Pad 不接受拖入。点击“试听”会先读取该采样，再由电脑播放；右上角 Loop 点亮时循环试听，熄灭时单次播放；播放中可随时切换，仅控制网页试听。WAV 下载保留机器上的原始文件。整页 ZIP 包含该 Bank 的全部文件、Pad 设置和校验清单。空 Pad 不会生成占位音频。

“批量上传采样”支持多选音频或拖入文件夹（包含子文件夹），按路径和文件名从指定 Bank / Pad 连续填充。先检查全部连续空位和音频；占用或越界时不开始上传，保留列表供处理后重试。关闭弹窗仍保留列表，刷新页面会清空。批量上传不恢复原备份的 Pad 设置；需要完整设置时使用复制/粘贴。

选择“打开备份文件夹”时，请选择包含 manifest.json 和 Bank01 等目录的备份根目录，或解压后的整页 ZIP 文件夹。选择的文件只在本页读取。

读取失败或取消后，重新连接设备即可继续。下载期间不要更改机器上的采样。网页单个文件上限 256 MB，整页上限 512 MB。上传支持 60 秒以内的单/双声道 WAV（PCM 8/16/24/32-bit、Float 32-bit），在本机转换为 48 kHz / 16-bit 双声道。只开放空 Pad；以单次播放、音量 100% 加载，不保留源文件的循环点等设置。上传期间请勿操作机器或同时连接官方 App。

有采样的 Pad 可点击“复制”，再到同一或其他 Bank 的空 Pad 点击“粘贴”。复制原始 WAV、波形、起止点、Pad 设置及同名前缀的附属文件，不重新编码；不包含 Pattern。每个复制文件最大 64 MB。“Edit 编辑”支持 Level、Pitch、Group、LED 颜色、Pan、One Shot、Loop、BPM；保存后核对实时参数和机器保存文件。编辑记录保留修改前后的设置。

在线版直接通过 HTTPS 地址使用；本地版可通过 localhost 服务或附带的启动器打开。网页试听播放原始 WAV，不模拟机器的播放参数。音频在本机处理，不上传到网站服务器；浏览器本地保留最近一次上传和编辑记录。离开页面会清空临时缓存和复制剪贴板，已下载的文件仍在电脑上。

非官方工具，与 CASIO 无隶属关系。已在 macOS / Chrome / 固件 1.4.1 上完成实机验证。
