# SXC-1 Web Editor

**简体中文 · [English](README.en.md)**

CASIO SXC-1 非官方网页采样管理器。通过 USB 和 Web MIDI 直接与机器通信，无需修改固件或安装官方 App。

**在线使用：[打开采样管理器](https://assong.github.io/SXC1WebEditer/)**

## 开始使用

1. 在电脑的 Chrome 或 Edge 中打开上面的 HTTPS 地址。
2. 正常开启 SXC-1，用支持数据传输的 USB 线连接机器的 **DATA** 接口。
3. 退出官方 App 和其他正在连接机器的编辑器。
4. 点击「连接 SXC-1」，允许浏览器访问 MIDI / SysEx。

页眉和弹窗中的语言选择器可在 English / 简体中文之间即时切换并记住选择，无需刷新页面或重新连接设备；文件名、路径和设备数据保持原样。未保存选择时，中文浏览器默认使用简体中文，其他语言默认使用 English。

已在 macOS + Chrome + SXC-1 固件 **1.4.1** 上完成实机验证。其他系统、浏览器与固件尚未完成实机验证；设备连接需要浏览器支持 Web MIDI / SysEx。

## 选择操作

| 想要做什么 | 操作 |
| --- | --- |
| 将新声音放入空 Pad | 「导入音频」→ 单个 WAV，或音频文件/文件夹 |
| 保存当前 Bank 到电脑 | 「备份采样 → 当前 Bank · ZIP」 |
| 保存所有有音频的 Bank | 「备份采样 → 全部 Bank · 文件夹」 |
| 浏览含一个或多个 Bank 的备份 | 「打开备份…」；ZIP 请先解压 |

导入音频会转换格式并使用默认 Pad 设置。备份保留原始文件和设置。打开备份只在电脑上浏览，不会将备份恢复到机器；本工具尚未提供备份恢复操作。

## 功能

- 按 80 个 Bank 浏览采样，网页翻页时机器跟随切换。
- Pad 1 在左下，四行依次为 13–16 / 9–12 / 5–8 / 1–4。
- Pad 右上角 Loop 开关控制网页循环试听，支持播放中切换；不修改机器上的 Loop 参数。
- 试听、下载单个原始 WAV、下载整页 ZIP（音频、Pad 设置和校验清单，不含 Pattern）。
- 选择或直接拖入 WAV 到空 Pad，自动转换并生成机器屏幕所需的波形。
- 批量选择音频或拖入文件夹，按路径与文件名排序，从指定 Bank / Pad 连续上传；检查空位不足时保留列表，处理后可直接重试。
- 复制 Pad 到同一或其他 Bank 的空 Pad，保留原始音频、波形、起止点、设置及关联文件。
- 编辑 Level、Pitch、Group、LED Color、Pan、One Shot、Loop、BPM，保存后读回核对。
- 打开本地备份文件夹，离线浏览、试听和下载。
- 一次备份全部 80 个 Bank 到电脑文件夹，自动跳过空 Bank 和没有音频的 Pad。

上传支持最长 60 秒、最大 64 MB 的单/双声道 WAV（PCM 8/16/24/32-bit、Float 32-bit，8–192 kHz），转换为 48 kHz / 16-bit 双声道。上传和粘贴仅允许空 Pad，已有采样或设置文件的 Pad 不可覆盖。普通上传使用默认设置；复制会保留原 Pad 设置。

Level 范围为 0–100%；Pitch 为 ±24 半音，会同时改变速度。网页试听播放原始 WAV，不模拟机器的播放参数。起止点可保留和复制，暂不提供编辑。机器上手动翻页不会反向同步网页。写入期间保持连接并避免同时操作设备；如提示结果待核对，请重新连接检查目标 Pad。

## 批量上传

通过「导入音频 → 单个 WAV」试听单个 WAV 并选择空 Pad；通过「导入音频 → 音频文件或文件夹」，多选音频、选择文件夹，或将文件/文件夹拖入窗口中的区域。会读取子文件夹，跳过隐藏和非音频文件，按路径与文件名的数字顺序排列；列表中可预览每个文件的目标位置。

设置起始 Bank（1–80）和 Pad（1–16）。Pad 16 后接下一 Bank 的 Pad 1，不跳过占用位置，也不循环到 Bank 1。上传前先检查整个范围的连续空位、逐个校验音频，再复查空位；范围越界、位置有音频或设置文件、任一音频无效时，本轮不会开始写入。处理后点击「重试上传」，无需重新选择文件；尚未写入时也可以调整起点或移除有问题的文件。

每个文件最长 60 秒、最大 64 MB，支持单/双声道。WAV 使用既有转换流程；MP3、FLAC、M4A 等取决于浏览器解码能力，无法解码时会提示。全部转换为 48 kHz / 16-bit 双声道并生成机器波形，以默认 Pad 设置加载。批量音频导入不恢复备份中的 `.wav.db` 设置。

上传逐个进行并读回校验。点击「停止」会等待当前 Pad 完成核对；重试跳过已完成项，先核对上次中断时结果不明的 Pad。已经写入的采样不会回滚。关闭弹窗保留列表与进度，刷新或离开页面会清空；可下载批量记录。此批量功能已通过模拟设备与浏览器测试，尚待真实机器批量写入验证。

## 备份全部 Bank

连接机器后，选择「备份采样 → 全部 Bank · 文件夹」，选择电脑上的目标文件夹。网页会检查全部 80 个 Bank；只有找到非空音频时，才在目标内创建新的 `SXC-1_AllBanks_…` 子文件夹。请使用支持文件夹访问的 Chrome 或 Edge。

仅保留名称为 `01.wav`–`16.wav` 且含有音频数据的 Pad，以及这些 Pad 的关联文件（包括 `.wav.db` 设置）。音频不重新编码，原始文件名、Bank 和 Pad 编号保持不变。静音录音仍是有效音频，会保留。缺失音频、零字节文件、没有音频数据的有效 WAV、仅含设置的 Pad 及其无用附属文件均跳过；没有保留音频的 Bank 不创建目录。

逐个保存并核对文件，不把全部音频放在内存中，也不受单 Bank ZIP 总大小限制；现有 USB 读取器仍限制单个文件不超过 256 MB。导出只读取目录与文件，不切换 Bank，不写入机器。读取前后比较目录文件名和长度，但无法保证不断变化内容的原子快照，请勿同时在机器上录音或编辑。

完成后，子文件夹含有 `manifest.json` 和 `SHA256SUMS.txt`，清单仅列出非空 Bank。可通过「打开备份…」选择此子文件夹离线浏览。不包含 Pattern 或全局设置；本功能不提供写回机器的恢复操作。

点击「取消」会停止导出，已保存文件仍保留；尽可能将清单标记为不完整。不能把未完成的目录视为完整备份。重试会创建另一个新子文件夹。全部为空时不创建备份。本功能已通过模拟设备、文件系统及浏览器测试，真实机器导出仍待验证。

## 文件与隐私

音频转换、试听、备份读取与 USB 通信都在浏览器本地完成；本工具不会把采样或设备备份上传到网站服务器。浏览器会在本地保留最近一次上传和编辑记录；关闭页面会清空临时音频缓存和复制剪贴板。GitHub Pages 提供网页文件的托管服务。

本仓库只发布网页及源代码，不包含设备采样、通信记录、固件或官方 App 安装包。

## 本地运行与更新

根目录 `index.html` 是无外部前端依赖的单文件页面。需要本地运行时，在仓库目录执行：

```sh
python3 -m http.server 8764 --bind 127.0.0.1
```

然后打开 `http://localhost:8764/`。在线版直接使用 HTTPS 地址即可。

修改 `src/` 后重新构建：

```sh
python3 -B src/build.py --output index.html
```

将更新后的源文件和 `index.html` 提交到 `main`。GitHub Pages 使用 `main` 分支根目录发布，提交后会自动更新网站。`.nojekyll` 保留在根目录。
